# 催收短信中心功能原型

独立 HTML 原型，用于演示租后催收的短信发送看板、发送明细、短信回复记录及案件详情触达统计。

## 查看方式

直接打开 `index.html`。

叁友短信详情页原型：`prototype/叁友短信详情页原型.html`。

## 覆盖范围

- 短信发送看板：批次监控、合计、筛选、分页及失败重发
- 发送情况明细：短信中心状态映射、频控拦截、敏感手机号查看
- 短信回复记录与案件详情当日触达统计
- 业务阶段消息类型：当天提醒、1-7队列、8-30队列、买断提醒、买断逾期
- 客户维度催收触达频控
- 管理角色全量查看与内部催员本人数据隔离
- 详情页短信发送方式 Tab：短信通道发送、叁友设备发送
- 叁友设备发送通过 `channelType=叁友` 选择叁友催收通道，且仅支持单条发送

所有操作仅为前端模拟，不发送真实短信，也不调用线上接口。
