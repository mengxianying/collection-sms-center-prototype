# 案件列表黑名单管理

## 最新维度规则

- 短信黑名单支持客户维度和手机号维度；外呼黑名单仅支持客户维度。
- 加入时按类型分别配置：短信有独立的客户/手机号维度选项及短信号码选择；外呼固定客户维度。勾选或取消外呼不改变短信的维度和号码选择。
- 同时选择短信和外呼时，可一次加入手机号维度短信记录和客户维度外呼记录。多选 N 个短信号码则生成 N 条短信记录和 1 条客户外呼记录，分别去重，独立编辑及移除。
- 未勾选的类型不参与校验或提交；取消勾选短信时保留其表单选择但隐藏配置，重新勾选可继续使用。
- 编辑时类型改为外呼，同样自动切换并锁定客户维度；保存时再校验，禁止外呼手机号维度记录。
- 原型外呼示例及本地缓存展示统一调整为客户维度。此调整仅用于演示数据，不代表线上历史数据迁移方案。
- 已在浏览器验证一次提交“目前使用手机号短信黑名单＋客户维度外呼黑名单”，返回管理弹窗后两条记录分别显示正确的类型、维度和范围。

案件列表操作列统一使用“黑名单管理”。有无生效记录都可打开，自动带入当前案件客户。

- 管理弹窗展示当前客户未移除记录，区分“生效中”和“被客户维度覆盖”，逐条显示类型、维度、限制范围及加入原因，提供编辑、移除。
- 加入：沿用客户锁定、类型多选、客户/手机号维度及三类手机号选择；成功后返回管理弹窗。
- 编辑：针对单条记录调整类型、维度、具体号码和原因。客户不允许更换；与另一生效记录完全重复时阻止保存。编辑保存即更新该记录限制，原范围不继续由该记录拦截；其他记录独立生效。
- 移除：沿用详情字段确认弹窗，不包含加入来源、操作记录、黄色提醒和移除原因。确认后仅移除所选记录，并返回当前客户管理弹窗。
- 取消加入、编辑或移除时回到管理弹窗，便于继续操作。
- 独立黑名单维护页继续提供全量查询、详情和移除；添加仍仅从案件列表的管理入口发起。

验证：浏览器走通短信按手机号与外呼按客户同时提交；外呼固定客户维度。走通已有客户维度时禁止添加手机号维度，以及加入客户维度后覆盖原手机号记录的流程。

本说明为当前交互口径，覆盖此前设计中案件列表直接展示“加入黑名单”及仅提供移除选择器的描述。


### 同时配置短信与外呼（2026-09-10）
- 加入弹框以两个独立设置区块展示，短信可选客户或手机号维度，外呼固定客户维度。
- 勾选或取消外呼不改变短信维度、已选手机号；短信手机号仅用于短信限制。
- 同时选择「短信 / 手机号」和「外呼 / 客户」时，分别保存指定号码短信记录和客户自动外呼记录，支持独立编辑、移除。

### 短信客户维度覆盖规则

- 已有未移除的客户维度短信记录时，加入弹框禁用短信手机号维度，并解释其已覆盖全部号码；提交和编辑均校验，禁止绕过入口增加手机号配置。
- 已有手机号维度短信记录时，允许加入客户维度。原手机号记录保留，状态为“被客户维度覆盖”，不单独生效、不计入生效数量；所有号码按客户维度禁止自动和手工短信。
- 维护列表增加“被客户维度覆盖”状态筛选，管理弹窗与详情同步展示状态。被覆盖记录可移除。
- 移除客户维度后，原未移除手机号记录自动恢复生效（用户已于2026-09-10确认）；确认弹框说明恢复记录数量。已移除的手机号记录不会恢复。
- 外呼记录不参与短信覆盖判断。


### 短信发送看板边界（2026-09-11）
- 黑名单仅影响短信实际发送动作：命中后阻止自动或手工发送。
- 黑名单不影响“短信发送看板”的页面访问、任务展示、筛选查询、统计口径及历史发送记录。
- 看板继续按原有任务与发送结果口径展示；被黑名单拦截的任务保留并展示拦截结果/原因，不删除、不隐藏、不回写为其他失败类型。
- 黑名单新增、编辑、移除不会触发看板数据重算或历史记录变更。

### 有效期与自动失效（2026-09-14）
- 新增字段“有效期截止日”，加入和编辑时必须选择具体日期或“长期有效”。
- 截止日当天 00:00 后自动失效，状态变更为“已失效”，不再拦截短信或自动外呼。
- 订单从“未逾期”转为“逾期”时，关联客户的黑名单立即自动失效，状态显示“已失效”。
- 已失效记录保留在维护列表，可按“已失效”筛选、查看详情和编辑；编辑为未来日期后恢复“生效中”。
- 被客户维度覆盖的手机号记录如果因截止日或订单逾期而失效，客户维度移除后不恢复；仍有效的被覆盖记录按原规则恢复。
- 历史存量短信黑名单初始化为“长期有效”，保持原有拦截效果。
