# 黑名单维护交互说明

更新日期：2026-09-14

## 一、功能规则与入口

- 每条记录对应一个客户、一种黑名单类型和一个具体手机号，不再提供客户维度、维度切换、客户覆盖或被覆盖状态。
- 短信黑名单拦截所选手机号的自动、手工短信；外呼黑名单仅拦截注册手机号的自动外呼，人工仍可拨打。
- 案件列表原“加入短信黑名单”入口统一为“黑名单管理”。加入从案件列表发起，独立维护页用于查询、详情、移除。

## 二、案件列表与客户管理

案件列表保留案件编号、客户姓名、注册手机号、催收员、短信限制、自动外呼、操作列。黑名单管理弹窗自动带入当前案件客户，客户不可更换；展示未移除记录（生效中、已失效），每条提供移除。

## 三、加入黑名单

| 字段 | 规则 |
| --- | --- |
| 黑名单类型 | 必选，可同时选择短信、外呼，至少一项。 |
| 控制范围 | 必选单选“全局控制/催收系统”，默认“全局控制”。 |
| 短信手机号 | 勾选短信后自动加载当前案件的注册、收货、目前使用手机号；相同号码合并并展示来源，可多选，至少一个。 |
| 外呼手机号 | 勾选外呼后自动展示注册手机号，固定不可修改；无注册手机号时禁止提交外呼。 |
| 有效期截止日 | 必选指定日期或长期有效；指定日期必须填写有效日期。 |
| 加入原因 | 必填，去首尾空格后不可为空，最多200字。 |

两类配置相互独立；取消类型后隐藏其配置、不校验、不提交。选择 N 个短信号码生成 N 条短信记录；同时选择外呼时另生成 1 条注册手机号外呼记录。按“客户＋类型＋手机号”去重，已有生效记录时不重复加入；部分重复仅保存新增项，全部重复时提示无需重复加入。已失效、已移除记录不阻止再次加入。控制范围、有效期、原因写入本次生成的各条记录。

## 四、移除

- 移除仅处理当前手机号记录，状态变为已移除并停止本条限制；其他号码或另一类型记录不受影响。记录保留供维护页查询，不物理删除。
- 详情和移除确认展示客户、类型、手机号及来源、控制范围、原因、有效期、加入人/时间、状态；不展示加入来源、操作记录或客户覆盖提示。

## 五、独立维护页

筛选：客户姓名、客户编号、手机号（按具体记录手机号匹配）、名单状态（生效中/已失效/已移除/全部，默认生效中）。短信、外呼分两个页签，数量统计生效记录；支持查询、重置、分页。

列表共7列：客户信息、限制手机号、加入原因、加入人/时间、有效期截止日、状态、操作。无维度筛选、维度列或维度标签；控制范围仅在详情和客户管理中展示。

## 六、有效期与自动失效

- 指定日期为最后有效日期，次日00:00自动变为“已失效”；长期有效无日期到期限制。失效记录不拦截、不计入生效数量，也不阻止重新加入。
- 关联订单从未逾期转为逾期时，黑名单立即失效。手机号记录独立计算状态。

## 七、历史数据与缓存

原有短信黑名单存量初始化为短信手机号记录：限制范围保留当初加入的手机号，加入原因为空，状态生效中，有效期长期有效；历史无控制范围按“全局控制”展示。原型使用独立 `phone-v2` 缓存，旧版客户维度缓存不读取；该处理仅为演示，不代表线上迁移方案。

## 八、短信发送看板边界

黑名单只影响短信实际发送动作，命中生效手机号时阻止自动或手工发送。看板访问、任务展示、筛选、统计和历史记录不变；拦截任务保留并展示拦截结果/原因。新增、移除、失效不触发看板重算；控制范围只记录展示，不改变拦截逻辑。

## 九、验收场景

1. 案件管理自动加载三类手机号，同号码合并，无维度切换；外呼自动带入且锁定注册手机号。
2. 同时配置时分别生成短信号码记录和外呼注册手机号记录，可独立移除。
3. 类型、控制范围、手机号、原因、有效期校验正确；重复记录按规则跳过。
4. 到期次日00:00或订单转逾期后停止拦截，状态和数量同步更新；失效/移除不阻止重新加入。
5. 维护页仅7列且无客户维度/覆盖文案；历史记录保留原手机号和空原因；短信看板口径不变。
