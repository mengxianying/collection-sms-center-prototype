# 黑名单库交互说明

更新日期：2026-09-16

## 一、功能规则与入口

- 每条记录对应一个客户、一种黑名单类型和一个具体手机号，不再提供客户维度、维度切换、客户覆盖或被覆盖状态。
- 短信黑名单拦截所选手机号的自动、手工短信，数据统一提交至基建中心；自动外呼黑名单仅拦截注册手机号的自动外呼，人工仍可拨打，数据只保存在租后系统。
- 案件列表原“加入短信黑名单”入口统一为“黑名单管理”。加入从案件列表发起，黑名单库用于查询、详情、移除。

## 二、案件列表与客户管理

案件列表保留案件编号、客户姓名、注册手机号、催收员、短信限制、自动外呼、操作列。黑名单管理弹窗自动带入当前案件客户，客户不可更换；展示未移除记录（生效中、已失效），每条提供移除。

## 三、加入黑名单

| 字段 | 规则 |
| --- | --- |
| 黑名单类型 | 必选，可同时选择短信、自动外呼，至少一项。 |
| 标签 | 必选下拉框：非本人手机号、客户投诉、手机号停机或空号、协商还款、其它。默认“其它”。 |
| 短信手机号 | 勾选短信后自动加载当前案件的注册、收货、目前使用手机号；相同号码合并并展示来源，可多选，至少一个。 |
| 系统来源 | 短信黑名单自动记录为“租后系统”，数据提交至基建中心；自动外呼黑名单固定为“租后系统（本地）”。 |
| 外呼手机号 | 勾选自动外呼后自动展示注册手机号，固定不可修改；无注册手机号时禁止提交。 |
| 有效期截止日 | 必选指定日期或长期有效；指定日期必须填写有效日期。 |
| 加入原因 | 必填，去首尾空格后不可为空，最多200字。 |

加入页面不再展示或要求选择范围。短信记录提交至基建中心并写入系统来源；自动外呼记录只写入租后系统。新建的自动外呼记录绑定当前案件，用于判断案件出催后的自动失效。

两类配置相互独立；取消类型后隐藏其配置、不校验、不提交。选择 N 个短信号码生成 N 条短信记录；同时选择自动外呼时另生成 1 条注册手机号记录。按“客户＋类型＋手机号”去重，已有生效记录时不重复加入；部分重复仅保存新增项，全部重复时提示无需重复加入。已失效、已移除记录不阻止再次加入。标签、系统来源、有效期、原因写入本次生成的各条记录。

## 四、移除

- 移除仅处理当前手机号记录，状态变为已移除并停止本条限制；其他号码或另一类型记录不受影响。记录保留供维护页查询，不物理删除。
- 详情和移除确认展示客户、类型、手机号、系统来源、标签、原因、有效期、加入人/时间、状态；不展示加入来源、操作记录或客户覆盖提示。

## 五、案件详情页黑名单展示

案件详情页新增“黑名单信息”区域，展示当前客户所有生效黑名单：黑名单类型、限制手机号、标签、系统来源、有效期截止日和状态。短信黑名单统一来自基建中心，法诉等其他系统设置的记录必须展示实际来源系统并影响租后案件；租后系统新增的短信记录来源显示“租后系统”。自动外呼黑名单来源显示“租后系统（本地）”，仅限制自动外呼。无记录时展示“当前客户暂无生效黑名单”。详情页只读，不提供加入、编辑或移除操作。

## 六、独立维护页

筛选：客户姓名、客户编号、手机号（按具体记录手机号匹配）、名单状态（生效中/已失效/已移除/全部，默认生效中）。短信、自动外呼分两个页签，数量统计生效记录；支持查询、重置、分页。

列表共8列：客户信息、限制手机号、系统来源、加入原因、加入人/时间、有效期截止日、状态、操作。无维度筛选、维度列、维度标签或来源范围列；短信来源可为其它系统，自动外呼固定显示“租后系统（本地）”。

## 七、有效期与自动失效

- 指定日期为最后有效日期，次日00:00自动变为“已失效”；长期有效无日期到期限制。失效记录不拦截、不计入生效数量，也不阻止重新加入。
- 关联订单从未逾期转为逾期时，黑名单立即失效。手机号记录独立计算状态。
- 新建的自动外呼记录绑定当前案件；案件出催后立即自动失效，并在状态和详情中显示“案件已出催，自动失效”。基建中心短信记录不受单个案件出催影响。

## 八、历史数据与缓存

原有短信黑名单存量初始化为短信手机号记录：限制手机号保留当初加入的手机号，加入原因为空，状态生效中，有效期长期有效；历史记录标签默认“其它”。原型使用独立 `phone-v2` 缓存，旧版客户维度缓存不读取；该处理仅为演示，不代表线上迁移方案。

## 九、短信发送看板边界

黑名单只影响短信实际发送动作，命中生效手机号时阻止自动或手工发送。看板访问、任务展示、筛选、统计和历史记录不变；拦截任务保留并展示拦截结果/原因。新增、移除、失效不触发看板重算；标签仅作记录和展示，不改变看板逻辑。

## 十、验收场景

1. 案件管理自动加载三类手机号，同号码合并，无维度切换；自动外呼自动带入且锁定注册手机号。
2. 同时配置时分别生成短信号码记录和自动外呼注册手机号记录，可独立移除。
3. 类型、标签、手机号、原因、有效期校验正确；重复记录按规则跳过。
4. 到期次日00:00或订单转逾期后停止拦截，状态和数量同步更新；失效/移除不阻止重新加入。
5. 黑名单库展示8列，短信记录显示系统来源，自动外呼显示租后系统本地；历史记录保留原手机号和空原因；短信看板口径不变。
