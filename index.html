短信发送看板

集中查看案件列表、买断催收及系统自动发送实际产生的短信批次和发送结果。发送中表示该批次未全部返回终态；全部有了终态结果即已完成。

发送批次

人工确认发送或自动任务实际执行后，系统按实际命中的短信模板创建批次；本页仅用于查询与监控。

备注说明

权限与查询说明

1. 默认查询时间为今天。
2. 操作员仅可查看本人创建的批次；管理角色可查看全部人工与系统自动批次，并按操作员筛选。
3. 系统自动批次的操作员固定展示“系统自动”，仅催收工作台管理角色可见。

自动发送归批

1. 自动任务每次实际执行时，按“自动任务 + 实际命中的短信模板 + 执行时间”生成批次。
2. 同一次任务命中多个模板时按模板分别生成批次；无符合条件订单时不生成空批次。
3. 自动发送与人工发送共用高优先级通道、频控拦截、回执和发送明细口径。
4. 现有示例：T-5/T-3/T-1 账单提醒（09:30）、T0 到期提醒（08:00）、T-20 买断提醒（10:30）、T0 晚班提醒（21:00）。

发送状态口径

1. 发送中：该批次已进入短信中心的明细未全部返回终态。
2. 已完成：已进入短信中心的明细全部有了终态结果；成功或失败均可完成。
3. 频控拦截在租后本地完成，未进入短信中心，不作为等待终态的条件。

消息类型与模板

1. 账单催收可选：当天提醒、1-7队列、8-30队列。
2. 买断催收可选：买断提醒、买断逾期；仅租赁业务展示。
3. 分期不展示买断类型；选择业务、发送类型和消息类型后，仅可选对应阶段已绑定的模板。

列表区说明

1. 批次由案件列表、买断催收等原有发送功能及系统自动任务实际发送后生成。
2. 消息类型按“租赁/分期（业务阶段）”展示，例如“租赁（当天提醒）”。
3. 频控拦截条数为提交时因客户当日短信频控而未进入发送的订单数。

失败重发

1. 仅对终态失败明细发起重发；成功、状态待返回及频控拦截不参与。
2. 重发沿用原短信内容并重新校验客户频控和通道可用性。
3. 原失败原因和重发操作记录保留，用于审计追溯。

短信回复记录

集中查看客户对催收短信的回复内容。

回复时间手机号客户姓名回复内容

备注说明

回复归属规则

1. 仅记录客户对已发送催收短信的有效回复。
2. 回复按手机号关联客户与订单，并记录对应的发送批次。
3. 无法匹配客户或订单的回复进入异常队列，由运营人工处理。

隐私与展示

手机号默认脱敏；完整手机号展示遵循敏感信息权限控制。客户姓名展示全名，不做截断或脱敏。回复内容仅用于催收跟进和审计，不得用于营销触达。

筛选匹配规则

手机号、客户姓名：精确匹配。
不提供回复内容查询条件。

权限与查询

1. 催收工作台可查看全部回复，并按操作员筛选。
2. 我的工作台仅查看本人发送批次关联的回复，操作员默认本人且不可变更。
3. 支持回复时间、手机号、客户姓名组合筛选；列表按回复时间倒序展示。

备注说明

权限与脱敏说明

1. 手机号默认脱敏展示。
2. 仅拥有敏感信息权限的用户可点击页面右上角小眼睛查看完整手机号。
3. 查看权限由服务端按登录用户实时校验，前端仅控制展示。

短信中心状态映射

已送达 → 成功。
发送三方成功、发送中 → 状态待返回。
发送三方失败、未送达 → 失败。
频控拦截为租后本地状态，未提交短信中心。

频控占位规则

1. 仅当成功送达数 + 待回执占位数小于日上限时，才可提交短信中心。
2. 已送达将占位转为成功；终态失败释放占位；待回执持续占位。
3. 同一客户的多手机号、多订单及多次连续发送共享当天额度。

明细筛选规则

手机号、客户姓名：精确匹配。

筛选与结果口径

1. 发送结果按租后业务状态筛选：成功、失败、频控拦截、状态待返回。
2. 状态待返回表示未收到最终送达结果，不计入成功次数。
3. 明细中的原始短信中心状态用于审计追溯。

追溯规则

明细仅展示当前批次的逐条发送结果；失败重发不覆盖原始失败原因，便于全链路审计追溯。

备注说明

今日触达统计规则

1. 今日短信、今日外呼均按客户 ID 在自然日内累计。
2. 同一客户存在多个手机号时合并计数，避免绕过频控。
3. 统计数据用于催收人员判断当日触达余量。

详情页短信发送

1. 在“需催订单列表”点击短信发送后，按当前订单和实际选择的模板立即创建 1 条短信批次。
2. 批次操作员为当前登录操作员；发送明细、回执、频控拦截和失败重发与案件列表发送口径一致。
3. 频控命中时不提交短信中心，并在明细中记录本地拦截原因。

展示位置

指标位于案件详情的“作业详情 → 客户信息 → 基本信息”区域，与客户手机号信息同屏展示。

新增模板绑定

新增后会增加一条消息模板下拉枚举项；删除绑定只移除当前枚举项，不影响基建中心模板、其它消息类型绑定或历史发送记录。

确认删除绑定

确认删除该模板绑定吗？

删除后，该模板将不再出现在当前消息类型的“消息模板”下拉中；不会删除基建中心模板，也不会影响历史发送和批次记录。
