# 叁友设备短信设计说明

## 1. 目标

在催收系统全部短信发送场景中，按手机号优先级自动路由并在失败或未送达时切换号码；在案件作业详情页增加叁友设备短信单条发送入口，支持独立模板、编辑和结果追踪。

## 2. 范围

号码路由覆盖系统自动、案件列表手工、案件详情手工发送。叁友设备短信为独立短信类型，不能批量发送，模板和类型单独配置；其发送同样使用统一号码路由。

## 3. 号码路由设计

本需求仅记录与号码路由的关联关系；号码路由规则以独立需求为准。

叁友设备发送提交至短信中心时，必须传递 `channelType=叁友`。短信中心根据该参数选择叁友催收通道发送；普通短信通道发送使用普通短信通道类型。该参数属于发送请求和批次明细的可追溯字段。

### 3.1 路由顺序

目前使用手机号 → 注册手机号 → 收货手机号。

空号码跳过；多个号码去重后只尝试一次。

### 3.2 切换规则

当前号码出现通道发送失败，或发送接口受理成功但最终回执为未送达时，切换下一号码重发同一业务短信。任一号码送达成功即结束任务；三个号码均完成尝试仍未成功，任务最终状态为失败。

### 3.3 数据与展示

一个业务短信只生成一个发送任务，任务下记录号码类型、脱敏号码、尝试顺序、发送时间、通道状态、回执时间和失败原因。看板统计按业务短信任务计数，切换尝试不重复计数；明细可查看完整尝试链路。

## 4. 叁友设备短信

案件作业详情页新增“叁友设备发短信”按钮。点击后打开单条发送弹窗，展示独立配置的叁友短信类型与模板，模板变量自动回填，正文可编辑后发送。弹窗不提供批量选择或批量发送能力。详情页短信弹窗支持“短信通道发送 / 叁友设备发送”切换，默认选中短信通道发送；列表页批量发送不展示叁友设备发送入口。

发送后记录案件、订单、叁友模板、编辑后正文、实际发送号码、每次路由尝试和最终结果。发送成功、失败、未送达及切换过程均可追溯。

## 5. 页面原型范围

- 案件作业详情页新增入口按钮。
- 叁友短信发送弹窗：短信类型、模板、变量回填、可编辑正文、字数提示、发送按钮。
- 路由尝试时间线：目前使用手机号、注册手机号、收货手机号三种状态。
- 发送成功、全部失败、号码为空跳过、最终未送达等状态。
